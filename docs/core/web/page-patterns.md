# Page patterns

Every site is assembled from the same page types and the same sections. A new section gets added
here first, then built, so the next site can use it too.

## Page types

| Page | Its job | Must have | One ask |
|---|---|---|---|
| **Home** | "That's me": the visitor sees themselves and the way forward | Hero, problem or promise, paths or offers, proof, CTA band | The brand's main ask |
| **Offer** (one per product or class) | Decide whether this is for them | Hero, who it's for, what you get, outcome, format, CTA band | The brand's main ask |
| **Lead magnet** (a free thing) | Trade an email for something useful | Hero, what you get, form | HubSpot form (medium heat) |
| **About** | Trust the people | The person or team, why we care, proof | The brand's main ask |
| **Contact** | Reach us with no friction | HubSpot form, then meetings where it fits, email, location | Book or send |
| **Legal** | Privacy, terms, accessibility | Plain text, last-updated date | None |
| **404** | Get them back on track | One line plus links to Home and the main ask | Home |

## Section library

| Section | What it must answer | Notes |
|---|---|---|
| **Hero** | What is this, and for whom? | One headline, one line under it, one primary button |
| **Problem** | What is hard right now, in their words? | Their words, not ours |
| **Promise / outcome** | What changes after? | Concrete, no hype words |
| **Paths** | Where do I start? | 2 to 4 cards, each one linking to an offer page |
| **Offer card** | What is it, who is it for, what format? | Same fields on every card |
| **Steps** | How does working together go? | 3 steps maximum |
| **What you get** | What exactly is included? | A list, not a paragraph |
| **Person** | Who is behind this? | Real photo, first person, short |
| **Proof** | Why believe it? | Real quotes with a name and role, or leave it out. Never invent one |
| **FAQ** | What stops people from acting? | Only questions people actually ask |
| **CTA band** | The ask, again, near the bottom | Same ask as the hero |
| **Form** | Capture the lead | HubSpot form with the hidden Brand field |
| **Meetings** | Book a time | HubSpot meetings embed |
| **Doors** (p3 only) | Which world do I want? | One card per brand, linking out to its site |
| **Footer** | Find anything, see who runs this | Nav, socials, contact, legal, the p3 line, © P to the 3 LLC |

## Rules

1. **One ask per page,** repeated in the hero and the CTA band. Other links are quieter.
2. **A section must earn its place.** If it has no real content (no real quotes, no real FAQ),
   it does not ship. A gap beats a placeholder.
3. **No template leftovers.** Lorem ipsum, "This is the space to introduce...", and stock
   features copied from a template are bugs.
4. **Every image has alt text** that says what is in it.
